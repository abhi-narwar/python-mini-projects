# Smart Student Expense & Performance Analyzer

This project is a GUI-based Python application developed using Tkinter.
It helps students track their daily expenses and analyze spending patterns.

## Problem Statement
Students often do not track daily expenses which leads to poor money
management and affects academic performance.

## Features
- Add daily expenses
- Store data in a text file
- Category-wise expense analysis
- Smart performance suggestion
- Simple GUI interface

## Technologies Used
- Python
- Tkinter
- File Handling

## How to Run
1. Install Python 3.x
2. Open terminal
3. Run command:
   python main.py

- Graphical charts
